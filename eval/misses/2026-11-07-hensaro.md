## Fixes (commit "scanner: research step (price + reputation), brand-on-page copycat, no SAFE with unchecked core signals")

- **Sent away to a big site** (search engine, portal) → "couldn't verify" (HOLD): "This shop sent our check to google.com instead of showing its product page. Real shops don't hide their pages."
- **Page facts:** product, price, currency from the rendered page (JSON-LD, meta, then the AI), plus the shop's shown identity (site name, logo alt, banner).
- **Price for pasted links:** Channel3 for the same product (median rule, ≥3 offers); fewer than 3 → web search prices (research step); 40%+ below → fail, with the stores named.
- **Another retailer's name on the page** (Costco, Walmart, Amazon…) on a non-retailer address → copycat fail, with the quote. Product makers and payment logos ("Amazon Pay") don't count.
- **What the web says** (research step, no points): up to 3 web searches about the domain, the shop's own site never searched; every finding must point at a real search result.
- **No SAFE with unchecked core checks:** page analysis didn't run on the page, and price, copycat and what the web says all not checked, plus anything worth a look → HOLD, "We couldn't check everything. Be careful." (Narrowed on Nov 7: when page analysis read the real page, a lone "worth a look" stays SAFE.)
- **AI prompt v7:** 70%+ off a big brand, or another retailer's banner, is a strong sign.
- **Tracking params stripped** before scanning, storing and caching.
